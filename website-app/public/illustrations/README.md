# Homepage illustrations

Original flat "human" scenes drawn for Wazelo (no third-party art, no licence
requirements). Generated by `scripts/draw-illustrations.mjs`:

```sh
# from website-app/
node scripts/draw-illustrations.mjs public/illustrations
```

Edit poses, colours or props in that script and re-run; don't hand-edit the SVGs.

## Animation hooks

`src/components/illustration.tsx` builds every file in (shapes appear in drawing
order) and then loops these hooks while on screen:

| Attribute | Effect |
|---|---|
| `data-anim="wave"` + `data-origin="x y"` | rotates (arm waving from the shoulder) |
| `data-anim="sway"` + `data-origin="x y"` | gentle rotation (plants) |
| `data-anim="float"` | drifts up and down (bubbles, cards, coins, confetti) |
| `data-anim="pulse"` | opacity pulse (online and notification dots) |

A file with no hooks falls back to floating its `#f59e0b` shapes.
